# Claude для Chrome (Windows 7)

Расширение для Google Chrome: чат с Claude прямо в браузере.
Сделано под **Chrome 109** — последнюю версию Chrome, которая работает на Windows 7
(без Side Panel и других функций новых версий Chrome).

## Возможности

- Чат с потоковым выводом ответа, Markdown, таблицы, блоки кода с кнопкой «Копировать».
- Модели: Claude Opus 5.5 (по умолчанию), Sonnet 5.5, Haiku 5.5, Fable 5.2.
- Настраиваемая глубина размышлений и показ хода размышлений.
- Несколько чатов с историей (хранится локально в браузере), экспорт в JSON.
- Картинки: кнопка 📎, вставка из буфера (Ctrl+V) или перетаскивание.
- 📄 во всплывающем окне — прикрепить текст открытой страницы.
- Контекстное меню: «Спросить Claude о выделенном» и «Кратко изложить страницу».
- Горячая клавиша **Alt+Shift+C** открывает окно Claude.
- Тёмная тема подхватывается из настроек Windows/Chrome.

## Установка

1. Скачайте папку `extension` (или весь репозиторий через *Code → Download ZIP* и распакуйте).
2. В Chrome откройте `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`.
5. Откроется страница настроек — вставьте API-ключ Anthropic и нажмите «Проверить».

Ключ берётся на <https://console.anthropic.com/settings/keys>. Использование API оплачивается
отдельно по факту, по тарифам Anthropic (это не подписка claude.ai).

> Закрепите значок расширения на панели (иконка пазла → булавка), чтобы открывать чат одним кликом.

## Если не работает на Windows 7

- Нужен Chrome 102 или новее (на Windows 7 — Chrome 109). Версию видно в `chrome://settings/help`.
- Сообщение «Нет соединения с api.anthropic.com» — проверьте интернет, прокси и что сайт
  не заблокирован провайдером или антивирусом. Нужен доступ к `https://api.anthropic.com`.
- Если сбиты системные часы, HTTPS-соединения не устанавливаются — проверьте дату и время.

## Для разработчиков

`extension/vendor/claude-api.js` — официальный SDK `@anthropic-ai/sdk`, собранный esbuild-ом
под `chrome109` из `src/api.js`. Готовая сборка уже лежит в репозитории; пересобрать:

```bash
npm install
npm run build
```

Безопасность: ключ хранится в `chrome.storage.local` и уходит только на `api.anthropic.com`.
Ответы модели экранируются перед отрисовкой Markdown, HTML из ответа не выполняется.
