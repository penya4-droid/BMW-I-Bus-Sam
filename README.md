# Бортовик: сайт-магазин с кошельком

| Папка | Что внутри |
|---|---|
| `public/` | сайт: `index.html` (главная, магазин, корзина, кошелёк, вопросы, контакты) |
| `server/` | сервер оплаты через ЮKassa и кошелёк: `server.js`, инструкция в `server/README.md` |

Сейчас сайт работает в демо-режиме: оплаты имитируются. Для приёма настоящих платежей нужно запустить `server/server.js` на сервере с Node.js 22+ и HTTPS, а затем подключить к нему страницу.

Ключи ЮKassa и другие секреты в репозиторий не кладутся: они хранятся в файле `.env` на сервере.
