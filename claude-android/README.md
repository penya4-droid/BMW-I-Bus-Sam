# Claude для Android (Chrome)

Chrome на Android **не поддерживает расширения**, поэтому для телефона сделано
устанавливаемое веб-приложение (PWA). Chrome сам предлагает «Установить приложение»,
после чего Claude открывается с главного экрана как обычное приложение — без адресной строки.

## Что умеет

- Встроенный чат с Claude по API-ключу (тот же, что в расширении для Windows 7):
  потоковые ответы, Markdown и код, несколько чатов, фото из галереи или камеры.
- **Бесплатно:** кнопки «Приложение Claude в Google Play» и «Открыть claude.ai» —
  официальный Claude на бесплатном тарифе (нужен аккаунт, есть дневной лимит).
- «Поделиться» → **Claude** из любого приложения (браузер, Telegram, заметки) — текст
  или ссылка сразу попадают в поле ввода.
- Работает без сети (открывается мгновенно; для ответов, конечно, нужен интернет).
- Кнопка «Назад» на телефоне закрывает настройки, а не приложение.
- Блок «Проверка»: браузер, установка, хранилище, связь с claude.ai и api.anthropic.com, API-ключ.

## Как выложить (бесплатно, GitHub Pages)

Chrome устанавливает приложения только с сайта по **HTTPS**. Для этого в репозитории есть
автовыкладка на бесплатный GitHub Pages (`.github/workflows/pages.yml`).

Адрес приложения: **https://penya4-droid.github.io/BMW-I-Bus-Sam/**

Настроить один раз:

1. На github.com откройте репозиторий → **Settings** → **Pages**.
2. В «Build and deployment» → **Source** выберите **GitHub Actions**.
3. Слейте ветку с изменениями в `main` (выкладка запускается из `main`).
4. Выкладка начнётся сама; повторить вручную: **Actions** → «Claude для Android на GitHub Pages» → **Run workflow**.
   Через 1–2 минуты приложение откроется по адресу выше.

Дальше каждое изменение в `claude-android/app/` в ветке `main` выкладывается автоматически.

## Как установить на телефон

1. Откройте адрес приложения в **Google Chrome** на Android.
2. Нажмите «Установить приложение» (кнопка на экране или в «Настройки и установка»).
   Если кнопки нет: меню Chrome **⋮** → «Установить приложение» / «Добавить на главный экран».
3. Значок Claude появится на главном экране.

## Безопасность и данные

- API-ключ и чаты хранятся только на телефоне (IndexedDB), ключ отправляется только на
  api.anthropic.com. Запросы по ключу платные, по тарифам Anthropic.
- Ответы модели экранируются перед отрисовкой, HTML из ответа не выполняется.
- claude.ai и API Anthropic работают только в [поддерживаемых странах](https://www.anthropic.com/supported-countries).

## Для разработчиков

`app/vendor/claude-api.js` — официальный SDK `@anthropic-ai/sdk`, собирается из
`../claude-chrome-win7/src/api.js` командой `npm run build` в папке `claude-chrome-win7`.
`app/markdown.js` и `app/style.css` общие с расширением. После изменения файлов увеличьте
версию кэша `CACHE` в `app/sw.js`, чтобы у пользователей подтянулось обновление.
