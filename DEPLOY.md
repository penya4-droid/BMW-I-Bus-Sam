# Как сайт попадает на хостинг

После каждого изменения в папке `public/` GitHub сам загружает сайт на Hostland по FTP. Настроить это нужно один раз.

## 1. Узнайте данные FTP в панели Hostland

В панели управления Hostland откройте раздел про FTP (доступ к файлам). Понадобятся:

- **адрес FTP-сервера**, например `ftp.bmw-ibus.ru` или адрес вида `xxx.hostland.ru`;
- **логин FTP**;
- **пароль FTP**;
- **папка сайта** на сервере, куда кладутся файлы домена bmw-ibus.ru (часто это папка с именем домена, внутри неё `htdocs` или `www`). Путь должен заканчиваться на `/`.

Если что-то не нашли, напишите в поддержку Hostland: «Подскажите FTP-сервер, логин и папку для сайта bmw-ibus.ru».

## 2. Впишите их в GitHub

На github.com откройте репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret** и добавьте по одному:

| Name | Значение |
|---|---|
| `FTP_SERVER` | адрес FTP-сервера |
| `FTP_USERNAME` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_DIR` | папка сайта, например `bmw-ibus.ru/htdocs/www/` |
| `FTP_PROTOCOL` | необязательно: `ftps`, если Hostland поддерживает защищённый FTP |

Эти значения видны только GitHub при выкладке. В коде и в чате их нет.

## 3. Запустите первую выкладку

Репозиторий → **Actions** → **Выкладка на хостинг** → **Run workflow**. Через минуту сайт откроется на bmw-ibus.ru. Зелёная галочка значит, что всё прошло, красный крестик означает ошибку: откройте его и пришлите текст.

## Сервер оплаты

Страница сейчас в демо-режиме. Сервер оплаты (`server/`) запускается отдельно через Node.js в панели Hostland, после договора с ЮKassa. Инструкция в `server/README.md`.
